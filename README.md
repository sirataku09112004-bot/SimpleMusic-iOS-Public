# SimpleMusic-iOS

SimpleMusicは、iPhoneに取り込んだ音楽をオフラインで再生するプレーヤーです。MP3、AAC、FLAC、WAV、Ogg Opus、Ogg Vorbisに対応します。ライブラリ検索、再生キュー、お気に入り、再生統計、音量正規化、設定のバックアップ・復元を備えています。

## 再生設定

- Siriや通話による中断後は、iOSが再開を許可した場合に同じ曲の続きから再生します。一時停止・停止の操作を優先します。
- 車で音楽を再生しているときに「再生設定」から出力先を登録できます。再生中に切断した車へ再接続したときに、続きからの再生を試みます。ショートカットのBluetoothオートメーションで車を指定し、「URLを開く」に `simplemusic://resume` を設定できます。再接続通知の配信やロック中のアプリ起動はiOSの制約を受けます。
- 他アプリとの音声同時再生は既定でONです。ロック画面やイヤホンからの操作対象に表示されない場合は、再生設定でOFFにできます。
- `simplemusic://shuffle` は従来のシャッフル再生ショートカット用です。

ライブラリと設定は端末内に保存します。アルバム画像の自動取得をONにしている場合、対応するメタデータからYouTubeの画像配信先に接続することがあります。

## ビルドとテスト

GitHubの **Actions → Test and build unsigned iOS IPA → Run workflow** で `main` を選びます。標準macOSランナー `xcode-27` とXcode 27.0を使用します。

CIはテスト用の音とアイコンを生成し、iOS 27シミュレーターでユニットテストとUI回帰テストを実行します。中断からの復帰条件、車の再接続条件、同時再生設定をテストします。専用Control WidgetのUIテストは実行対象外です。Siri、通話、Bluetooth、他アプリと実際に音声を同時再生した際の挙動はiPhoneで確認してください。

テスト成功後、署名なしIPAを作り、Bundle ID、署名用ファイル、ライセンス通知、既知の個人情報パターンを検査します。Actionsの成果物 `SimpleMusic-unsigned-ipa` からIPA、SHA-256、テスト件数、第三者ライセンス通知を取得できます。

## AltStore Classicでの更新

事前にSimpleMusicの「バックアップ・復元」で設定・統計・キューをアプリ外に書き出し、元の音楽も別途保管してください。現在のSimpleMusicを残し、同じApple IDで署名し、同じインストール済みアプリIDへ上書きします。拡張の選択は現在のインストールに合わせてください。

署名先やアプリIDが異なると表示された場合は、そこで作業を止めてください。更新後は曲数、お気に入り、再生統計、キューが引き継がれているか確認してください。
